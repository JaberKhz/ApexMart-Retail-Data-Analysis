# 📊 ApexMart Retail Data Analysis & Executive Dashboard

## 📖 Project Overview
This project is an end-to-end data analysis solution built entirely in Microsoft Excel. It transforms raw, fragmented retail data into a fully interactive Executive Dashboard designed to drive strategic business decisions. 

* **The Problem:** Discrepancies in sales and returns reports across different channels, with raw data full of inconsistencies and errors.
* **The Objective:** Unify the data, build an accurate and robust Data Model, and create a dynamic management dashboard to track performance.
* **The Achievements:** Cleaned hundreds of thousands of records, merged multiple dimensional tables, built Key Performance Indicators (KPIs), and uncovered actionable insights regarding product profitability, regional performance, and return rates.

## 🚀 Key Business Insights Extracted
Through rigorous analysis, this project answered critical management questions:
1. **Revenue Trends:** Identified a severe sales slump in Q3, followed by a +19.04% MoM recovery in December, prompting a review of seasonal marketing strategies.
2. **Profitability vs. Volume:** Discovered that the highest-revenue products (Laptops) yield lower profit margins (15.7%) compared to accessories like Monitors (21.9%), leading to a cross-selling recommendation.
3. **Return Rate Mitigation:** Pinpointed the Furniture category as the highest driver of returns (2.76%) and proposed logistical and web-display improvements.
4. **Regional Leadership:** Highlighted the West and North regions as top performers, exceeding the $125M revenue mark and outperforming their targets.
5. **Top Talent Recognition:** Identified top-performing sales representatives based on Average Order Value (AOV) to lead future training initiatives.

## 🛠️ Technical Skills & Tools Showcased
* **Data Cleaning & ETL:** Handled missing values, standardized formats, and resolved data anomalies.
* **Data Modeling:** Established relationships between Fact and Dimension tables (Star Schema concept applied in Excel).
* **Advanced Formulas:** Utilized complex logical, lookup, and aggregation functions for profitability and variance analysis.
* **Interactive Dashboarding:** Built dynamic visualizations using Combo Charts, Bar Charts, Slicers, and Timelines.
* **UI/UX Design:** Applied a "Modern Corporate" aesthetic focusing on data-ink ratio, clean layouts, and intuitive navigation.

## 💡 How to Interact with the Dashboard
1. Download the `ApexMart_Data_Analysis_Portfolio.xlsx` file.
2. Open it in Microsoft Excel (Desktop version recommended for full functionality).
3. Navigate to the **Executive Dashboard** sheet.
4. Use the left sidebar **Slicers (Region, Category)** and the top **Timeline** to dynamically filter the KPIs and charts.
